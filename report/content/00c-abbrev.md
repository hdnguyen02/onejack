| Từ viết tắt | Tiếng Anh | Nghĩa tiếng Việt |
|---|---|---|
| API | Application Programming Interface | Giao diện lập trình ứng dụng |
| BCP | Best Current Practice | Tài liệu thực hành tốt nhất của IETF |
| BGP | Border Gateway Protocol | Giao thức định tuyến giữa các hệ tự trị |
| CPU | Central Processing Unit | Bộ xử lý trung tâm |
| CSV | Comma-Separated Values | Tệp dữ liệu phân tách bằng dấu phẩy |
| DDoS | Distributed Denial of Service | Tấn công từ chối dịch vụ phân tán |
| DNS | Domain Name System | Hệ thống phân giải tên miền |
| DoS | Denial of Service | Tấn công từ chối dịch vụ |
| DSCP | Differentiated Services Code Point | Mã phân loại dịch vụ trong tiêu đề IP |
| EF | Expedited Forwarding | Lớp chuyển tiếp ưu tiên |

| IP | Internet Protocol | Giao thức Internet |
| KVM | Kernel-based Virtual Machine | Máy ảo dựa trên nhân Linux |

| QoS | Quality of Service | Chất lượng dịch vụ |

| RTT | Round-Trip Time | Thời gian khứ hồi |

| TCP | Transmission Control Protocol | Giao thức điều khiển truyền vận |
| TOS | Type of Service | Byte loại dịch vụ trong tiêu đề IP |
| TTL | Time To Live | Thời gian tồn tại |
| UDP | User Datagram Protocol | Giao thức gói tin người dùng |
| VPN | Virtual Private Network | Mạng riêng ảo |
